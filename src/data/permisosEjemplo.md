# Sistema de Permisos Expandido

## Nuevos Permisos Agregados

### Permisos de Sistema y Administración
- **Gestionar Usuarios**: Crear, editar, eliminar y gestionar usuarios del sistema
- **Gestionar Roles**: Crear, editar roles y permisos
- **Ver Dashboard Admin**: Acceso al panel administrativo y métricas
- **Ver Perfil**: Ver y editar perfil personal

### Permisos de Productos e Inventario
- **Gestionar Productos**: Crear, editar, eliminar productos del catálogo
- **Ver Productos**: Consultar información de productos
- **Gestionar Categorías**: Crear, editar, eliminar categorías de productos
- **Ver Categorías**: Consultar categorías de productos
- **Gestionar Proveedores**: Crear, editar, eliminar proveedores
- **Ver Proveedores**: Consultar información de proveedores

### Permisos de Ventas y Clientes
- **Gestionar Ventas**: Realizar, editar y gestionar ventas
- **Ver Ventas**: Consultar reportes y datos de ventas
- **Gestionar Clientes**: Crear, editar, eliminar clientes
- **Ver Clientes**: Consultar información de clientes
- **Gestionar Cotizaciones**: Crear, editar, aprobar cotizaciones
- **Ver Cotizaciones**: Consultar cotizaciones existentes

### Permisos de Pedidos y Entregas
- **Gestionar Pedidos**: Crear, editar, procesar pedidos de clientes
- **Ver Pedidos**: Consultar estado de pedidos
- **Procesar Pedidos**: Cambiar estados y gestionar el flujo de pedidos
- **Cancelar Pedidos**: Cancelar pedidos cuando sea necesario

### Permisos de Compras y Aprovisionamiento
- **Gestionar Compras**: Crear, editar y gestionar órdenes de compra
- **Ver Compras**: Consultar historial de compras
- **Aprobar Compras**: Aprobar órdenes de compra
- **Realizar Compras Cliente**: Realizar pedidos como cliente en la tienda

### Permisos de Devoluciones y Garantías
- **Gestionar Devoluciones**: Procesar, aprobar y gestionar devoluciones
- **Ver Devoluciones**: Consultar devoluciones existentes
- **Aprobar Devoluciones**: Aprobar o rechazar solicitudes de devolución

### Permisos de Notas de Crédito
- **Gestionar Notas Crédito**: Crear, editar y gestionar notas de crédito
- **Ver Notas Crédito**: Consultar notas de crédito existentes
- **Procesar Notas Crédito**: Procesar y aplicar notas de crédito

### Permisos de Abonos y Pagos
- **Gestionar Abonos**: Registrar, editar y gestionar abonos de pagos
- **Ver Abonos**: Consultar historial de abonos
- **Procesar Abonos**: Validar y procesar abonos de clientes

### Permisos de Reportes y Analytics
- **Ver Reportes Ventas**: Acceso a reportes detallados de ventas
- **Ver Reportes Compras**: Acceso a reportes de compras y costos
- **Ver Reportes Inventario**: Reportes de stock y movimientos de inventario
- **Exportar Datos**: Exportar datos en formatos PDF, Excel, etc.

### Permisos de Configuración
- **Configuración Sistema**: Acceso a configuraciones generales del sistema
- **Gestionar Parámetros**: Modificar parámetros y configuraciones operativas

### Permisos Especiales
- **Acceso Total**: Acceso completo a todas las funcionalidades
- **Auditoría**: Ver logs y auditoría del sistema
- **Backup Restauración**: Realizar copias de seguridad y restauraciones

## Nuevos Roles Implementados

### 1. Administrador
- **Descripción**: Acceso completo al sistema con todos los permisos administrativos
- **Permisos**: Todos los permisos disponibles

### 2. Empleado
- **Descripción**: Acceso operativo completo para gestión de ventas, productos, pedidos y clientes
- **Permisos**: Acceso a dashboard, gestión de productos, ventas, clientes, pedidos, compras, devoluciones, notas de crédito, abonos y reportes

### 3. Cliente
- **Descripción**: Acceso básico para compras y gestión de cuenta personal
- **Permisos**: Ver perfil, productos, categorías, sus pedidos, devoluciones, notas de crédito y abonos

### 4. Supervisor Ventas
- **Descripción**: Supervisión de procesos de ventas, pedidos y atención al cliente
- **Permisos**: Dashboard, gestión completa de ventas, clientes, cotizaciones, pedidos, devoluciones, notas de crédito, abonos y reportes de ventas

### 5. Supervisor Inventario
- **Descripción**: Gestión completa de inventario, productos y compras
- **Permisos**: Dashboard, gestión de productos, categorías, proveedores, compras, aprobación de compras y reportes de inventario

### 6. Vendedor
- **Descripción**: Operaciones de venta directa y atención al cliente
- **Permisos**: Gestión de ventas, clientes, cotizaciones, pedidos, abonos y reportes de ventas

## Beneficios del Sistema Expandido

1. **Control Granular**: Permisos específicos para cada módulo y operación
2. **Flexibilidad**: Múltiples roles predefinidos para diferentes necesidades
3. **Seguridad**: Acceso restringido basado en responsabilidades
4. **Escalabilidad**: Fácil adición de nuevos permisos y roles
5. **Trazabilidad**: Mejor control sobre quién puede hacer qué en el sistema
